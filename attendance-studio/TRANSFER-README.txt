ATTENDANCE STUDIO WEB APP - LAPTOP TRANSFER

1. Extract the whole ZIP into a folder on the other laptop. Keep the
   attendance-studio, NOMINAL ROLLS and the two .cmd files together.
2. Install Python 3.11 or newer for Windows. Enable the Python launcher (py).
3. Double-click Setup Attendance Web.cmd once. Internet is needed to install
   the Python packages. Wait for “Setup complete”.
4. Double-click Start Attendance Web.cmd. It opens the app in the browser.
   Keep the command window open while using the app; close it to stop the app.

No separate Node, Excel or desktop executable is needed. The nominal rolls
are included in this ZIP. CDC and class attendance input files are not.

For a server deployment, see attendance-studio/DEPLOYMENT.md. This local
transfer package runs only on that laptop; it does not publish the app online.
